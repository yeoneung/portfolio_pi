# Continuous certificates for a locally coupled factor cycle

This experiment uses a structured policy distinct from the supplied
seed-11 neural policy. It tests the
certification layer on 3, 5, 10, 20, and 50 **state variables** (and the same
number of assets). It does not run the manuscript's full policy-iteration or
Newton solver in those dimensions. The generating candidate is explicitly
log-quadratic with 15 coefficients, optimized on a GPU; it is not a dense
neural network. Every reported certificate is then checked without Torch.

## 1. Financial model and normalization

Let indices be cyclic, with `z_(d+1)=z_1`, and take independent d-dimensional
Brownian motions W and W0. Under the physical measure,

```
dZ_i = (-kappa Z_i + epsilon Z_(i+1)) dt
       + G dW_i + sqrt(Q-G^2) dW0_i,
dX/X = (r + pi'lambda(Z)) dt + pi'dW,
lambda_i(z) = (lambda0 + A z_i + B z_(i+1))/sqrt(d),
|pi_i| <= C/sqrt(d).
```

All model numbers are exact rationals:

| Parameter | Value |
| --- | ---: |
| kappa, epsilon | 1, 1/5 |
| Q, G | 1/16, 1/8 |
| lambda0, A, B | 1/5, 1/2, 1/4 |
| C, r | 11/100, 3/100 |
| horizon T, risk aversion gamma | 1, 2 |
| implementation/certification cube radius, main sweep | 3/2 |

The asset covariance is the identity. The state covariance is Q times the
identity, with nonzero coupling in both drift and return predictors. The
unspanned covariance is `(Q-G^2)I=(3/64)I`; the symmetric part of the
mean-reversion matrix is at least `0.8 I`. The return-predictor matrix
`A I+B S` has smallest singular value at least `A-|B|=1/4`, before the
normalization. Thus the state problem has full-rank predictors and does not
consist of independent one-factor copies. Clipping also prevents a rotation
to independent scalar investment problems. An independent test exhibits two
states with the same mean and squared norm but different Bellman residuals.

The `1/sqrt(d)` scaling is important: it keeps aggregate exposure and the
typical aggregate investment-opportunity scale comparable as d increases.
In particular, `||pi||<=C`; per-asset opportunities do not stay fixed as
assets are added. The hedging term in the local formula below decreases like
`1/sqrt(d)`. These are favorable structural features, not evidence of
uniform performance for arbitrary high-dimensional markets.

With gamma=2, maximizing utility `-E[1/X_T]` is equivalent to minimizing the
positive factor `g=E[1/X_T]` at initial unit wealth. Under the policy tilt,

```
b^pi(z) = -kappa z + epsilon S z - G pi,
c^pi(z) = -r - pi'lambda(z) + ||pi||^2,
g^pi = E^pi[exp(integral c^pi ds)].
```

Bounded controls give a valid finite-horizon change of measure. No assertion
that the *controlled* state is Gaussian is used.

## 2. Frozen candidate, policy, and exact residual identity

For remaining time tau, the stored base candidate is

```
log u_base(tau,z) = -r tau + (1/d) sum_i f_base(tau,z_i),
f(tau,x) = a(tau) + b(tau)x + c(tau)x^2,
a(tau),b(tau),c(tau) in span{tau T_j(2 tau-1): j=0,...,4}.
```

Every coefficient is stored as an exact dyadic rational with denominator
dividing `2^36`. Let

```
l(x,y) = lambda0 + A x + B y,
s_base(tau,x,y) = l(x,y) + (G/sqrt(d)) f_base,x(tau,x),
p_base = clip(s_base/2, -C, C),
pi_i = p_base(tau,z_i,z_(i+1))/sqrt(d).
```

This policy is used inside the implementation cube. Outside that cube risky
exposures are zero; upon re-entry the same greedy policy resumes. It is
bounded and progressively measurable. The policy stays frozen throughout
all evaluation and verification comparisons.

For any log-quadratic evaluation f and a specified local scaled control p,
define the **forward** normalized residual

```
F(f,p;tau,x,y) = f_tau + (kappa x-epsilon y) f_x
                - (Q/2) f_xx - Q/(2d) f_x^2
                + p [l(x,y)+(G/sqrt(d))f_x] - p^2.
```

Direct substitution into the full d-dimensional generator gives

```
(u_tau - L^pi u)/u = (1/d) sum_i F(f,p_i;tau,z_i,z_(i+1)).
```

This is an algebraic equality, not a sampled approximation. The term
`Q f_x^2/(2d)` comes from the full Hessian of `exp(log u)`. The short rate
cancels because `log u` contains `-r tau`. For the Bellman residual use the
greedy control generated by the evaluation f itself. For a frozen-policy
upper evaluation use p_base, **not** the greedy control of that evaluation.

The LP can also introduce a potential

```
P(tau,x)=e(tau)x+d(tau)x^2,
e,d in span{T_j(2 tau-1): j=0,...,4}.
```

Adding `P(tau,y)-P(tau,x)` to each edge residual changes their sum by
exactly zero around the cycle. Consequently a uniform bound on one
three-variable local residual implies the same bound on the full
d-dimensional residual. Every edge is covered by the same template because
this experiment is cyclically homogeneous. No cover of a d-dimensional
tensor grid is substituted with random samples.

## 3. Lower and upper evaluations on a bounded domain

On the lateral boundary of the certification cube, prescribe the trace
`psi=u_base`. This is explicit approximate boundary data, not the exact
optimal or policy value. At tau=0 all candidates equal 1.

Two independent polynomial proposals fL,fU and potentials are constructed.
For fL use its own greedy control, giving the Bellman residual. For fU use
the fixed base control, giving the linear frozen-policy residual. Let the
continuous verifier return upper bounds on

```
eta_L >= max(0, sup(F(fL,greedy[fL])+delta P_L),
                sup((fL-f_base)/tau)),
eta_U >= max(0, sup(-F(fU,p_base)-delta P_U),
                sup((f_base-fU)/tau)).
```

The trace quotients extend polynomially to tau=0 because every f contains
an explicit tau factor. Define repaired evaluations

```
fL_hat=fL-eta_L tau,     fU_hat=fU+eta_U tau.
```

These repairs do not change state derivatives or the fixed policy. They
shift the corresponding normalized residuals by `-eta_L` and `+eta_U`.
The lower Bellman residual is therefore nonpositive, the upper fixed-policy
residual is nonnegative, and `fL_hat<=f_base<=fU_hat` on every boundary
face. Parabolic comparison on the bounded cube yields

```
uL_hat <= g_D^* <= g_D^pi <= uU_hat.
```

The same argument can be obtained by stopped stochastic verification,
including edges and corners of the cube; it requires no Schauder regularity
claim at nonsmooth corners. The coefficients and proposed test functions
are smooth within each control branch, clipping is continuous, and the
usual uniformly elliptic bounded-domain comparison assumptions hold.

At initial state z=0, tau=1, `T_j(1)=1`, so the evaluation endpoints are
computed directly from the stored a-coefficients and the verified repair
rates. This is not an evaluation at a random initial point.

## 4. Continuous, outward-rounded verification

The verifier performs the following checks independently of proposal fitting:

1. Construct power-polynomial coefficients using `mpmath.iv` at 60 decimal
   digits, including an interval enclosure of the exact `sqrt(d)`.
2. Form negative, interior, and positive clipping branches. In the upper
   interior branch the Hamiltonian term is
   `s_base*s_upper/2-s_base^2/4`; it is not `s_upper^2/4`.
3. Transform each polynomial from `(tau,x,y) in [0,1]x[-R,R]^2` to a tensor
   Bernstein basis using rational affine and binomial weights. The common
   degrees are `(10,2,2)` in this sweep.
4. Round coefficient endpoints outward to binary64. Bisect using outward
   de Casteljau arithmetic. All clipping branches compatible with the
   interval signal enclosure remain in the bound, including uncertain
   active-set crossings.
5. Accept a cell only when all residual/trace repair bounds are at most
   `1/2000`. The certificate uses the *actual* worst accepted bounds, not
   an assumed zero residual. Accepted cells must have exact dyadic total
   volume one. Exhausting the depth or cell budget raises an error, not a
   partial certificate.

These are machine-assisted certificates conditional on the stated model,
comparison argument, interval implementation, and ordinary IEEE-754
arithmetic. The tests cross-check the full generator and branch formulas
against independently differentiated 80-digit expressions. Tests are
additional checks; sampled test values are not the continuous proof.

## 5. Policy-uniform whole-space localization

The main certification cube has R=3/2. The truncation error is included, not
discarded on the ground that boundary visits were absent in simulations.

Until the first cube exit, each tilted coordinate has drift
`-kappa Z_i + v_i`, with

```
|v_i| <= d0 = epsilon R + G C/sqrt(d).
```

Starting at zero, the integrating-factor martingale has deterministic
quadratic variation
`N(t)=Q (exp(2 kappa t)-1)/(2 kappa)`. If a coordinate first reaches an
absolute value R in the time bin `[t_(j-1),t_j]`, one of its signed
martingales reaches at least

```
A_j = exp(kappa t_(j-1)) (R-d0/kappa) + d0/kappa.
```

Here `R>d0/kappa`. The exponential maximal-martingale inequality followed
by a union over signs, bins, and all d coordinates gives

```
p_exit <= min(1, 2 d sum_j exp(-A_j^2/(2 N(t_j)))).
```

There are 128 equal time bins. This bound is valid under every admissible
policy tilt; the Brownian integrating-factor martingale is used only up to
the stopped event. It does not replace the controlled diffusion with an OU
Gaussian transition distribution.

For a whole-space continuation envelope take
`omega(z)=exp(a ||z||^2/d)`, `a=1/20`, and `x=||z||/sqrt(d)`. Write

```
D_a = 2a(kappa-epsilon) - 2Q a^2/d > 0,
c0 = C^2+C lambda0,
c1 = C(|A|+|B|),
L_a = aQ+c0+[2a G C/sqrt(d)+c1]^2/(4D_a).
```

Cauchy--Schwarz and maximization of a scalar quadratic imply uniformly in
pi that `(L^pi omega)/omega <= L_a`, where L includes the running term
c^pi. Hence the continuation factor is at most
`exp(L_a T) omega(z)`. At a cube exit, `||z||^2<=dR^2`.

Let Mpsi be the verified upper bound on the prescribed trace and

```
cplus=max(0,-r+C^2+C[|lambda0|+(|A|+|B|)R]).
ell=exp(cplus T) [exp(L_a T+aR^2)+Mpsi] p_exit.
```

The stopped Feynman--Kac representation gives the same additive bound ell
for every policy's boundary-replacement error. Taking infima gives the
optimal-factor bound too. Thus at the origin

```
g_whole^* >= L=uL_hat-ell,
g_whole^pi <= U=uU_hat+ell.
```

With `L>0`, the relative certainty-equivalent loss is at most `1-L/U`.
The code evaluates these expressions outward and fails if the lower
endpoint is nonpositive. Gamma=2 is essential to this particular CE formula.

In the radius sensitivity, the implementation cube remains R=3/2 and the
same policy continues beyond the smaller *certification* cube. The proof
only uses the policy's agreement inside that cube and its global exposure
bound. The continuation estimate is valid for its unchanged outside
behavior. Consequently this sensitivity changes the certificate, not the
implemented policy.

## 6. An elementary alternative lower endpoint

A Gaussian-envelope/Jensen bound is also evaluated, to avoid attributing
all benefit to the lower PDE barrier when a simpler bound is better. Put
`a0=kappa-epsilon` and `L0=|A|+|B|`. Under any policy tilt write the state as
an uncontrolled OU convolution Y driven by the tilted Brownian motion plus
a pathwise bounded control displacement. Semigroup contraction gives

```
E||lambda(Z_t)||^2 <= B(t),
B(t) = [sqrt(lambda0^2 + L0^2 Q(1-exp(-2a0 t))/(2a0))
        + L0 G C(1-exp(-a0 t))/(a0 sqrt(d))]^2.
```

This uses the Gaussian law only for Y, not for the controlled state Z.
Since `c^pi>=-r-||lambda||^2/4`, Jensen's inequality gives

```
g_whole^* >= exp(-rT-(1/4) integral_0^T B(t) dt).
```

B is nondecreasing. A 1,024-bin right Riemann sum with interval arithmetic
therefore yields a rigorous upper bound on its integral. The hybrid result
uses the larger of this elementary lower endpoint and the localized PDE
lower endpoint, together with the **same certified policy upper endpoint**.
This is not a separate method for certifying the policy upper endpoint.
The elementary lower bound is better in four of the five main cases.

## 7. Matched comparison and experimental design

Main proposals: 600 Adam updates, seed 1103, float64 GPU computation on an
RTX 5070. Each update uses 2,048 joint state vectors: 98% stationary
physical OU samples, 2% uniform cube samples. These are proposal-fitting
distributions only. Two evaluation barriers are then proposed by three
sequential LP steps on a `17 x 49 x 49` grid (the spatial grid is the union
of a 33-point cube grid and a 17-point central grid). The verifier does not
trust any of these samples.

The matched time-only baseline retains all spatial coefficients of f_base
exactly, while optimizing its time-only correction and the same class of
telescoping potentials. It uses the same frozen policy, trace, cube,
clipping, continuous verifier, repair tolerance, localization formula,
and financial metric. To make its proposal sufficiently resolved it is
given a denser `129 x 81 x 81` collocation grid. Baseline coefficients remain
subject to the independent continuous check. Its stronger proposal grid is
not hidden in the timing comparison.

This is an **internal evaluation-method comparison**, not a rerun of a
named external paper or a claim of superiority over financial-duality
methods. The report provides both the two-sided PDE results and the
stronger elementary-lower-endpoint hybrid results for both methods.

Independent diagnostics use 65,536 stationary *physical* joint-state
samples, seed 9152026. Active-set frequencies at tau=1 are state-space
diagnostics, not controlled-path occupation probabilities. They demonstrate
nontrivial constraints but do not certify their frequency. Training losses
and held-out residuals never enter the proof as global upper bounds.

This is an exploratory sweep, not a preregistered experiment. A 100 bp
threshold is used for interpreting the results, not as an optimized theorem
constant. The 3D pilot did not close at repair tolerance `1/10000`; it
closed after choosing `1/2000`. The time-only baseline's preliminary
17-time-point grid failed the same `1/2000` cover; a 33-time-point grid
passed at d=3 but failed at d=5. The final 129-time-point grid passes at
all reported dimensions. Failed covers produced no successful certificate
for those attempts. Finer solver proposals and proof repairs are explicitly
distinct operations.

## 8. What the experiment establishes and its scope

It establishes computable **continuous-domain, whole-space welfare bounds**
for these genuinely multi-state, locally coupled constrained models through
50 state dimensions, including active-set crossings and artificial-boundary
error. The exact local residual decomposition is the reason the verifier
does not enumerate a d-dimensional tensor grid.

It does not establish certification of an arbitrary dense neural network,
performance with dense state interactions or general covariance matrices,
dimension-independent constants, or high-dimensional convergence of the
manuscript's Newton/policy-iteration algorithm. Symmetry, bounded local
interaction degree, additive log-quadratic evaluation, identity asset
covariance, and financial normalization are substantive restrictions.
The main cube is about 8.4 stationary coordinate standard deviations wide
in each direction, making the exit term small. The smaller-cube stress
test shows why the localization term must still be tracked as dimension
increases. Establishing a general novelty claim requires a separate
literature comparison and broader models; these runs alone do not do that.

## 9. Reproduction

Run from the project or standalone package root. Verification needs only
NumPy and mpmath; fitting additionally needs SciPy and Torch/CUDA.

```powershell
python -B experiments/highdim_local_verify.py --dimensions 3 5 10 20 50
python -B experiments/highdim_local_verify.py --dimensions 3 5 10 20 50 --folder results/highdim_local/time_only
python -B experiments/highdim_local_verify.py --dimensions 10 20 50 --radius 1
python -B -m pytest -q tests/test_highdim_local.py
python -B analysis/report_highdim_local.py
```

To regenerate proposals in the development workspace (this overwrites this
experiment's candidate files and requires verification again):

```powershell
python -B experiments/highdim_local_fit.py --dimensions 3 5 10 20 50 --epochs 600 --degree 5
python -B experiments/highdim_local_diagnostics.py
```

Exact numerical training reproducibility across GPU/library versions is not
assumed. Certificates refer to the exact stored coefficient files and the
verifier source hash. Re-verifying those files is independent of training.
The standalone builder reruns all main, time-only, and radius certificates
in an isolated extracted directory and compares every non-timing field.
The original neural checkpoint is checked to remain unchanged.
